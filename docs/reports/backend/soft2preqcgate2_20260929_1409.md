# soft2preqcgate2 — SSO + Oracle 세션 인증 구축

> 새 프로젝트: `soft2preqcgate2` / 기본 패키지 `com.soft2preqcgate2`
> 기준: soft2cost2의 인증 구조(토큰 헤더 `X-Auth-Token` + 세션 스냅샷 + 메뉴 권한)를 그대로 따르되, **Redis 없이** Oracle 테이블에 세션을 저장합니다.
> SSO: 한화오션 레거시 시스템 **Ocean Dev**. 세부 연동 사양이 아직 없으므로, **사양이 나오면 `OceanDevSsoProvider` 한 파일과 설정값만 채우면 되는 구조**로 만듭니다. 그 전까지는 개발용 가짜 SSO(`MockSsoProvider`)로 전체 흐름을 시험할 수 있습니다.
> 화면: Nexacro 웹 브라우저(HTML5) 실행.
> 코딩 지침: 모든 Service는 인터페이스 + 구현 클래스(`...Impl`)로 나눴습니다.
> 모든 파일은 **새 파일 생성**입니다.
> 검증: 이 보고서의 코드 블록을 그대로 꺼내 만든 임시 프로젝트에서 **컴파일 성공**을 확인했습니다. 세션 JSON 저장·복원과 권한 계산은 시험 코드로 **통과**를 확인했습니다. Oracle 연결, 화면 흐름, Ocean Dev 연동은 실제 환경이 없어 확인하지 못했습니다.

## 0. 질문 6 답변 — "비상용 로컬 계정"이란

**SSO 서버가 멈췄을 때도 시스템에 들어갈 수 있도록 남겨 두는, 아이디·비밀번호로 로그인하는 관리자 계정**입니다.

- **실제 예:** Ocean Dev SSO 서버가 점검 중이거나 장애가 나면, 모든 사용자가 soft2preqcgate2에 로그인할 수 없습니다. 이때 관리자가 `ADMIN` / 비밀번호로 직접 로그인해 권한 설정을 고치거나 상태를 확인합니다.
- **SSO 연동 전 개발 단계:** Ocean Dev 사양이 나오기 전에도 이 계정으로 로그인해 메뉴·권한 화면을 개발할 수 있습니다.

**이 보고서의 기본값:** 비상용 로컬 계정을 **두되, 허용된 아이디만** 로그인할 수 있게 했습니다.
- `local-login.enabled: true`
- `allowed-login-ids: ADMIN`
- 일반 사용자는 모두 SSO(`AUTH_TYPE = 'SSO'`)로만 로그인합니다.
- 운영에서 로컬 로그인을 완전히 막고 싶으면 `local-login.enabled: false`로 바꾸면 됩니다. 코드 수정은 필요 없습니다.

### 2-2. soft2cost2와 달라지는 점

| 구분 | soft2cost2 | soft2preqcgate2 |
|---|---|---|
| 세션 저장소 | Redis (`RedisAuthSessionService`) | Oracle 테이블 `S2P_AUTH_SESSION` (`AuthSessionService` → `AuthSessionServiceImpl`) |
| 만료 처리 | Redis 유지 시간(TTL)이 자동 삭제 | SQL 조건 `EXPIRES_AT > SYSTIMESTAMP` + 30분마다 정리 작업 |
| 토큰 필터 | `RedisTokenFilter` | `AuthTokenFilter` (내용은 같고 저장소 이름만 뺌) |
| 로그인 입구 | 아이디·비밀번호 1개 | **SSO** + 비상용 아이디·비밀번호 |
| SSO 교체 지점 | 없음 | `SsoProvider` 인터페이스 (가짜 / Ocean Dev 구현 교체) |

> 저장소를 인터페이스(`AuthSessionService`) 뒤에 두었기 때문에, 나중에 Redis로 돌아가야 하면 `RedisAuthSessionServiceImpl`을 하나 새로 만들면 됩니다. 필터·컨트롤러·로그인 코드는 바꿀 필요가 없습니다.

### 2-3. SSO 로그인 흐름

| 순서 | 어디서 | 무엇을 |
|---|---|---|
| 1 | Nexacro | `GET /api/v1/auth/sso/login-url` 호출 → `loginUrl` 받음 |
| 2 | Nexacro | 브라우저 주소를 `loginUrl`로 이동 (Ocean Dev 로그인 화면, 개발 중에는 가짜 로그인 화면) |
| 3 | Ocean Dev | 로그인 성공 후 `http://(API)/api/v1/auth/sso/callback`으로 돌려보냄 (GET 또는 POST 모두 받음) |
| 4 | API `SsoServiceImpl` | ① 위조 방지 값(`state`) 검증 → ② `SsoProvider.verify()`로 Ocean Dev에 사용자 확인 → ③ `S2P_USER.SSO_EXTERNAL_ID`로 등록 사용자 조회 → ④ 60초짜리 1회용 교환 코드 발급 |
| 5 | API | Nexacro 주소로 이동: `http://(Nexacro)/index.html?ssoCode=교환코드` (실패 시 `?ssoError=오류코드`) |
| 6 | Nexacro | `POST /api/v1/auth/sso/exchange {"ssoCode": "..."}` → `accessToken` 받음 |
| 7 | Nexacro | 이후 모든 요청에 `X-Auth-Token: accessToken` (soft2cost2와 같음) |

**교환 코드(5·6단계)를 쓰는 이유:** 레거시 SSO는 결과를 **POST 폼**으로 보내는 경우가 많습니다. Nexacro 정적 화면은 POST를 직접 받을 수 없어서, API가 먼저 받은 뒤 짧은 1회용 코드로 넘겨줍니다. 또 `accessToken`을 브라우저 주소창에 노출하지 않기 위해서입니다.

## 5. 데이터베이스

### `db/migration/V001__create_auth_tables.sql`

```sql
/* ============================================================
   1. 사용자
   AUTH_TYPE = 'SSO'   : Ocean Dev 로그인. SSO_EXTERNAL_ID(사번) 필수, 비밀번호 없음
   AUTH_TYPE = 'LOCAL' : 비상용 아이디·비밀번호 로그인. PASSWORD_HASH 필수
   ============================================================ */
CREATE TABLE S2P_USER
(
    USER_ID            NUMBER GENERATED BY DEFAULT AS IDENTITY,
    LOGIN_ID           VARCHAR2(50)  NOT NULL,
    USER_NAME          VARCHAR2(100) NOT NULL,
    DEPT_ID            NUMBER,
    EMAIL              VARCHAR2(200),

    AUTH_TYPE          VARCHAR2(20)  DEFAULT 'SSO' NOT NULL,
    SSO_EXTERNAL_ID    VARCHAR2(100),
    PASSWORD_HASH      VARCHAR2(255),

    USER_STATUS        VARCHAR2(20)  DEFAULT 'ACTIVE' NOT NULL,
    FAILED_LOGIN_COUNT NUMBER        DEFAULT 0 NOT NULL,
    LOCKED_UNTIL       TIMESTAMP,
    LAST_LOGIN_AT      TIMESTAMP,

    USE_YN             CHAR(1)       DEFAULT 'Y' NOT NULL,
    CREATED_AT         TIMESTAMP     DEFAULT SYSTIMESTAMP NOT NULL,
    CREATED_BY         VARCHAR2(50),
    UPDATED_AT         TIMESTAMP,
    UPDATED_BY         VARCHAR2(50),

    CONSTRAINT PK_S2P_USER PRIMARY KEY (USER_ID),
    CONSTRAINT UK_S2P_USER_LOGIN UNIQUE (LOGIN_ID),
    CONSTRAINT UK_S2P_USER_SSO UNIQUE (SSO_EXTERNAL_ID),
    CONSTRAINT CK_S2P_USER_AUTH CHECK (AUTH_TYPE IN ('SSO', 'LOCAL')),
    CONSTRAINT CK_S2P_USER_AUTH_VALUE CHECK (
        (AUTH_TYPE = 'SSO'   AND SSO_EXTERNAL_ID IS NOT NULL) OR
        (AUTH_TYPE = 'LOCAL' AND PASSWORD_HASH  IS NOT NULL)
    ),
    CONSTRAINT CK_S2P_USER_STATUS CHECK (USER_STATUS IN ('ACTIVE', 'LOCKED', 'INACTIVE')),
    CONSTRAINT CK_S2P_USER_USE CHECK (USE_YN IN ('Y', 'N'))
);

/* ============================================================
   2. 역할
   ============================================================ */
CREATE TABLE S2P_ROLE
(
    ROLE_ID    NUMBER GENERATED BY DEFAULT AS IDENTITY,
    ROLE_CODE  VARCHAR2(50)  NOT NULL,
    ROLE_NAME  VARCHAR2(100) NOT NULL,
    USE_YN     CHAR(1)       DEFAULT 'Y' NOT NULL,
    CREATED_AT TIMESTAMP     DEFAULT SYSTIMESTAMP NOT NULL,
    CREATED_BY VARCHAR2(50),

    CONSTRAINT PK_S2P_ROLE PRIMARY KEY (ROLE_ID),
    CONSTRAINT UK_S2P_ROLE_CODE UNIQUE (ROLE_CODE),
    CONSTRAINT CK_S2P_ROLE_USE CHECK (USE_YN IN ('Y', 'N'))
);

/* ============================================================
   3. 사용자 - 역할
   ============================================================ */
CREATE TABLE S2P_USER_ROLE
(
    USER_ROLE_ID NUMBER GENERATED BY DEFAULT AS IDENTITY,
    USER_ID      NUMBER  NOT NULL,
    ROLE_ID      NUMBER  NOT NULL,
    VALID_FROM   DATE    DEFAULT SYSDATE NOT NULL,
    VALID_TO     DATE,
    USE_YN       CHAR(1) DEFAULT 'Y' NOT NULL,
    CREATED_AT   TIMESTAMP DEFAULT SYSTIMESTAMP NOT NULL,
    CREATED_BY   VARCHAR2(50),

    CONSTRAINT PK_S2P_USER_ROLE PRIMARY KEY (USER_ROLE_ID),
    CONSTRAINT FK_S2P_UR_USER FOREIGN KEY (USER_ID) REFERENCES S2P_USER (USER_ID),
    CONSTRAINT FK_S2P_UR_ROLE FOREIGN KEY (ROLE_ID) REFERENCES S2P_ROLE (ROLE_ID),
    CONSTRAINT CK_S2P_UR_PERIOD CHECK (VALID_TO IS NULL OR VALID_TO >= VALID_FROM),
    CONSTRAINT CK_S2P_UR_USE CHECK (USE_YN IN ('Y', 'N'))
);

CREATE INDEX IX_S2P_UR_USER ON S2P_USER_ROLE (USER_ID);

/* ============================================================
   4. 메뉴
   ============================================================ */
CREATE TABLE S2P_MENU
(
    MENU_ID        NUMBER GENERATED BY DEFAULT AS IDENTITY,
    PARENT_MENU_ID NUMBER,
    MENU_CODE      VARCHAR2(50)  NOT NULL,
    MENU_NAME      VARCHAR2(100) NOT NULL,
    MENU_LEVEL     NUMBER        NOT NULL,
    FORM_PATH      VARCHAR2(200),
    SORT_ORDER     NUMBER        DEFAULT 0 NOT NULL,
    USE_YN         CHAR(1)       DEFAULT 'Y' NOT NULL,
    CREATED_AT     TIMESTAMP     DEFAULT SYSTIMESTAMP NOT NULL,

    CONSTRAINT PK_S2P_MENU PRIMARY KEY (MENU_ID),
    CONSTRAINT UK_S2P_MENU_CODE UNIQUE (MENU_CODE),
    CONSTRAINT FK_S2P_MENU_PARENT FOREIGN KEY (PARENT_MENU_ID) REFERENCES S2P_MENU (MENU_ID),
    CONSTRAINT CK_S2P_MENU_USE CHECK (USE_YN IN ('Y', 'N'))
);

/* ============================================================
   5. 역할별 메뉴 권한  (N: 없음 / R: 조회 / W: 저장)
   ============================================================ */
CREATE TABLE S2P_ROLE_MENU_AUTH
(
    ROLE_ID    NUMBER  NOT NULL,
    MENU_ID    NUMBER  NOT NULL,
    AUTH_LEVEL CHAR(1) DEFAULT 'N' NOT NULL,
```

```java
import com.soft2preqcgate2.auth.config.AuthProperties;

            "/api/v1/auth/sso/login-url",
            "/api/v1/auth/sso/callback",
            "/api/v1/auth/sso/exchange",
            "/api/v1/auth/sso/mock-login"

    public static final List<String> SWAGGER_URLS = List.of(
            "/swagger-ui/**",
            "/swagger-ui.html",
            "/v3/api-docs/**"
    );

    private final AuthSessionService authSessionService;
    private final ApiErrorWriter apiErrorWriter;
    private final ApiAuthenticationEntryPoint authenticationEntryPoint;
    private final ApiAccessDeniedHandler accessDeniedHandler;
    private final AuthProperties authProperties;
    private final String allowedOrigin;
    private final boolean swaggerEnabled;

    public SecurityConfig(
            AuthSessionService authSessionService,
            ApiErrorWriter apiErrorWriter,
            ApiAuthenticationEntryPoint authenticationEntryPoint,
            ApiAccessDeniedHandler accessDeniedHandler,
            AuthProperties authProperties,
            @Value("${soft2preqcgate2.cors.allowed-origin}") String allowedOrigin,
            @Value("${soft2preqcgate2.security.swagger-enabled:false}") boolean swaggerEnabled
    ) {
        if (allowedOrigin == null || allowedOrigin.isBlank()) {
            throw new IllegalStateException("soft2preqcgate2.cors.allowed-origin is required");
        }
        this.authSessionService = authSessionService;
        this.apiErrorWriter = apiErrorWriter;
        this.authenticationEntryPoint = authenticationEntryPoint;
        this.accessDeniedHandler = accessDeniedHandler;
        this.authProperties = authProperties;
        this.allowedOrigin = allowedOrigin;
        this.swaggerEnabled = swaggerEnabled;

    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
```

### `AuthTokenFilter.java`

```java
package com.soft2preqcgate2.common.security;

import com.soft2preqcgate2.auth.model.AuthSessionContext;
import com.soft2preqcgate2.auth.service.AuthSessionService;
import com.soft2preqcgate2.common.error.ApiErrorWriter;
import jakarta.servlet.FilterChain;
import jakarta.servlet.ServletException;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import org.springframework.http.HttpStatus;
import org.springframework.security.authentication.UsernamePasswordAuthenticationToken;
import org.springframework.security.core.authority.SimpleGrantedAuthority;
import org.springframework.security.core.context.SecurityContextHolder;
import org.springframework.web.filter.OncePerRequestFilter;

import java.io.IOException;
import java.util.Optional;

/**
 * soft2cost2 RedisTokenFilter 와 같은 역할.
 * X-Auth-Token 으로 세션 저장소(AuthSessionService)를 조회해 인증 객체를 만든다.
 * 저장소가 Oracle 이든 Redis 이든 이 필터는 바뀌지 않는다.
 */
public class AuthTokenFilter extends OncePerRequestFilter {

    public static final String TOKEN_HEADER = "X-Auth-Token";

    private final AuthSessionService authSessionService;
    private final ApiErrorWriter apiErrorWriter;
    private final boolean swaggerEnabled;

    public AuthTokenFilter(AuthSessionService authSessionService, ApiErrorWriter apiErrorWriter, boolean swaggerEnabled) {
        this.authSessionService = authSessionService;
        this.apiErrorWriter = apiErrorWriter;
        this.swaggerEnabled = swaggerEnabled;
    }

    @Override
    protected boolean shouldNotFilter(HttpServletRequest request) {
        if ("OPTIONS".equalsIgnoreCase(request.getMethod())) {
            return true;
        }
        String uri = request.getRequestURI();
        if (SecurityConfig.PUBLIC_URLS.contains(uri)) {
            return true;
        }
        return swaggerEnabled
                && (uri.startsWith("/swagger-ui") || uri.startsWith("/v3/api-docs"));
    }

    @Override
    protected void doFilterInternal(HttpServletRequest request, HttpServletResponse response, FilterChain filterChain)
            throws ServletException, IOException {

        String accessToken = request.getHeader(TOKEN_HEADER);

        try {
            Optional<AuthSessionContext> session = authSessionService.find(accessToken);
            if (session.isPresent()) {
                AuthSessionContext context = session.get();
                var authorities = context.roleCodes().stream()
                        .map(role -> new SimpleGrantedAuthority("ROLE_" + role))
                        .toList();
                var authentication = new UsernamePasswordAuthenticationToken(context, null, authorities);
                SecurityContextHolder.getContext().setAuthentication(authentication);
            }
        } catch (AuthSessionService.SessionStoreException exception) {
            SecurityContextHolder.clearContext();
            apiErrorWriter.write(response, HttpStatus.SERVICE_UNAVAILABLE.value(), "E503",
                    request.getRequestURI(), "인증 세션 저장소를 사용할 수 없습니다.");
            return;
        }

        filterChain.doFilter(request, response);
    }

}
```

### `PermissionGuard.java`

```java
package com.soft2preqcgate2.common.security;

import com.soft2preqcgate2.auth.model.AuthSessionContext;
import com.soft2preqcgate2.auth.model.MenuPermission;
import com.soft2preqcgate2.common.error.ApiException;
import org.springframework.http.HttpStatus;
import org.springframework.stereotype.Component;

/** 메뉴별 권한 검사. 사용 예: permissionGuard.require(session, "QC_GATE_LIST", "W") */
@Component
public class PermissionGuard {

    public MenuPermission require(AuthSessionContext session, String menuCode, String requiredLevel) {
        if (session == null || menuCode == null) {
            throw denied();
        }
        MenuPermission permission = session.menus().stream()
                .filter(menu -> menuCode.equals(menu.menuCode()))
                .findFirst()
                .orElseThrow(this::denied);
        if (rank(permission.authLevel()) < rank(requiredLevel)) {
            throw denied();
        }
        return permission;
    }

    private int rank(String level) {
        if ("W".equals(level)) {
            return 2;
        }
        if ("R".equals(level)) {
            return 1;
        }
        return 0;
    }

    private ApiException denied() {
        return new ApiException("E304", HttpStatus.FORBIDDEN, "요청한 기능에 대한 권한이 없습니다.");
    }

}
```

```java
package com.soft2preqcgate2.auth.service;

import com.soft2preqcgate2.auth.model.AuthSessionContext;

import java.util.Optional;

/**
 * 인증 세션 저장소 계약.
 * 구현: AuthSessionServiceImpl (Oracle S2P_AUTH_SESSION).
 * Redis 로 바꿀 때는 이 인터페이스의 구현 클래스만 새로 만든다.
 */
public interface AuthSessionService {

    /** 세션 발급. 원본 accessToken 은 반환값으로만 전달하고 저장소에는 SHA-256 해시만 저장한다. */
    IssuedSession issue(AuthSessionContext source);

    /** 토큰이 비었거나, 세션이 없거나, 만료되었으면 빈 값. 저장소 장애는 SessionStoreException. */
    Optional<AuthSessionContext> find(String accessToken);

    /** 토큰 하나의 세션 삭제. 비었거나 이미 없는 토큰이어도 오류 없이 끝난다. */
    void logout(String accessToken);

    /** 사용자의 모든 세션 삭제 (권한 변경, 사용자 비활성화 시 호출) */
    void logoutAll(Long userId);

    /** 만료된 세션과 SSO 교환 코드 정리. 삭제한 세션 건수를 반환한다. */
    int deleteExpired();

    record IssuedSession(
            String accessToken,
            AuthSessionContext context
    ) {}

    final class SessionStoreException extends RuntimeException {
        public SessionStoreException(String message, Throwable cause) {
            super(message, cause);
        }
    }

}
```

### `auth/service/AuthSessionServiceImpl.java`

```java
package com.soft2preqcgate2.auth.service;

import com.soft2preqcgate2.auth.config.AuthProperties;
import com.soft2preqcgate2.auth.mapper.AuthSessionMapper;
import com.soft2preqcgate2.auth.model.AuthSessionContext;
import org.springframework.stereotype.Service;
import tools.jackson.databind.ObjectMapper;

import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import java.security.NoSuchAlgorithmException;
import java.security.SecureRandom;
import java.time.Duration;
import java.time.Instant;
import java.util.Base64;
import java.util.Objects;
import java.util.Optional;

@Service
public class AuthSessionServiceImpl implements AuthSessionService {

    private final AuthSessionMapper authSessionMapper;
    private final ObjectMapper objectMapper;
    private final Duration sessionTtl;
    private final SecureRandom secureRandom = new SecureRandom();

    public AuthSessionServiceImpl(AuthSessionMapper authSessionMapper,
                                  ObjectMapper objectMapper,
                                  AuthProperties authProperties) {
        long ttlMinutes = authProperties.sessionTtlMinutes();
        if (ttlMinutes < 10 || ttlMinutes > 1440) {
            throw new IllegalStateException("session-ttl-minutes must be between 10 and 1440");
        }
        this.authSessionMapper = authSessionMapper;
        this.objectMapper = objectMapper;
        this.sessionTtl = Duration.ofMinutes(ttlMinutes);
    }

    @Override
    public IssuedSession issue(AuthSessionContext source) {
        Objects.requireNonNull(source, "source");

        String accessToken = createToken();
        String tokenHash = hashToken(accessToken);

        Instant issuedAt = Instant.now();
        AuthSessionContext context = new AuthSessionContext(
                source.userId(), source.loginId(), source.userName(), source.deptId(), source.authType(),
                source.roleCodes(), source.menus(), issuedAt, issuedAt.plus(sessionTtl));

        try {
            String json = objectMapper.writeValueAsString(context);
            authSessionMapper.insertSession(tokenHash, context.userId(), context.authType(), json,
                    sessionTtl.toMinutes());
            return new IssuedSession(accessToken, context);
        } catch (Exception exception) {
            throw new SessionStoreException("세션 발급 실패", exception);
        }
    }

    @Override
    public Optional<AuthSessionContext> find(String accessToken) {
        if (accessToken == null || accessToken.isBlank() || accessToken.length() > 200) {
            return Optional.empty();
        }
        try {
            String json = authSessionMapper.selectActiveSessionJson(hashToken(accessToken));
            if (json == null) {
                return Optional.empty();
            }
            return Optional.of(objectMapper.readValue(json, AuthSessionContext.class));
        } catch (Exception exception) {
            throw new SessionStoreException("세션 조회 실패", exception);
        }
    }

    @Override
    public void logout(String accessToken) {
        if (accessToken == null || accessToken.isBlank() || accessToken.length() > 200) {
            return;
        }
        try {
            authSessionMapper.deleteSession(hashToken(accessToken));
        } catch (Exception exception) {
            throw new SessionStoreException("세션 삭제 실패", exception);
        }
    }

    @Override
    public void logoutAll(Long userId) {
        if (userId == null) {
            return;
        }
        try {
            authSessionMapper.deleteSessionsByUserId(userId);
        } catch (Exception exception) {
            throw new SessionStoreException("사용자 세션 전체 삭제 실패", exception);
        }
    }

    @Override
    public int deleteExpired() {
        int deleted = authSessionMapper.deleteExpiredSessions();
        authSessionMapper.deleteExpiredSsoHandoffs();
        return deleted;
    }

    private String createToken() {
        byte[] bytes = new byte[32];
        secureRandom.nextBytes(bytes);
        return Base64.getUrlEncoder().withoutPadding().encodeToString(bytes);
    }

    static String hashToken(String value) {
        try {
            MessageDigest digest = MessageDigest.getInstance("SHA-256");
            byte[] hash = digest.digest(value.getBytes(StandardCharsets.UTF_8));
            return Base64.getUrlEncoder().withoutPadding().encodeToString(hash);
        } catch (NoSuchAlgorithmException exception) {
            throw new IllegalStateException("SHA-256 is not available.", exception);
        }
    }

}
```

### `auth/service/PermissionServiceImpl.java`

```java
package com.soft2preqcgate2.auth.service;

import com.soft2preqcgate2.auth.model.MenuPermission;
import com.soft2preqcgate2.auth.model.MenuRow;
import com.soft2preqcgate2.auth.model.RoleMenuAuthRow;
import org.springframework.stereotype.Service;

import java.util.Comparator;
import java.util.HashMap;
import java.util.HashSet;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;
import java.util.Set;

@Service
public class PermissionServiceImpl implements PermissionService {

    @Override
    public List<MenuPermission> calculate(List<MenuRow> menus, List<RoleMenuAuthRow> roleMenuAuths) {

        Map<Long, String> levelByMenu = new HashMap<>();
        for (RoleMenuAuthRow row : roleMenuAuths) {
            levelByMenu.merge(row.menuId(), normalize(row.authLevel()), this::max);
        }

        Map<Long, MenuRow> menuById = new LinkedHashMap<>();
        for (MenuRow menu : menus) {
            menuById.put(menu.menuId(), menu);
        }

        // 권한(R/W)이 있는 메뉴와 그 상위 메뉴를 표시 대상으로 모은다.
        Set<Long> visible = new HashSet<>();
        for (Map.Entry<Long, String> entry : levelByMenu.entrySet()) {
            if (rank(entry.getValue()) == 0) {
                continue;
            }
            Set<Long> path = new HashSet<>();
            Long current = entry.getKey();
            while (current != null && menuById.containsKey(current)) {
                if (!path.add(current)) {
                    throw new IllegalStateException("메뉴 상위 관계가 순환합니다. menuId=" + current);
                }
                visible.add(current);
                current = menuById.get(current).parentMenuId();
            }
        }

        return menus.stream()
                .filter(menu -> visible.contains(menu.menuId()))
                .map(menu -> new MenuPermission(
                        menu.menuId(),
                        menu.parentMenuId(),
                        menu.menuCode(),
                        menu.menuName(),
                        menu.menuLevel(),
                        menu.formPath(),
                        menu.sortOrder(),
                        levelByMenu.getOrDefault(menu.menuId(), "N")))
                .sorted(Comparator
                        .comparing(MenuPermission::menuLevel, Comparator.nullsLast(Comparator.naturalOrder()))
                        .thenComparing(MenuPermission::sortOrder, Comparator.nullsLast(Comparator.naturalOrder()))
                        .thenComparing(MenuPermission::menuId))
                .toList();
    }

    /** 알 수 없는 값은 권한 없음(N)으로 본다. */
    private String normalize(String level) {
        return "R".equals(level) || "W".equals(level) ? level : "N";
    }

    private String max(String left, String right) {
        return rank(left) >= rank(right) ? left : right;
    }

    private int rank(String level) {
        if ("W".equals(level)) {
            return 2;
        }
        if ("R".equals(level)) {
            return 1;
        }
        return 0;
    }
```

```java
@Service
public class AuthServiceImpl implements AuthService {

    private static final Logger log = LoggerFactory.getLogger(AuthServiceImpl.class);

    private final AuthMapper authMapper;
    private final PermissionService permissionService;
    private final AuthSessionService authSessionService;
    private final PasswordEncoder passwordEncoder;
    private final AuthProperties.LocalLogin localLogin;
    private final Set<String> allowedLocalLoginIds;
    private final String dummyPasswordHash;

    public AuthServiceImpl(AuthMapper authMapper,
                           PermissionService permissionService,
                           AuthSessionService authSessionService,
                           PasswordEncoder passwordEncoder,
                           AuthProperties authProperties) {
        this.authMapper = authMapper;
        this.permissionService = permissionService;
        this.authSessionService = authSessionService;
        this.passwordEncoder = passwordEncoder;
        this.localLogin = authProperties.localLogin();
        this.allowedLocalLoginIds = localLogin.allowedLoginIds().stream()
                .map(id -> id.trim().toUpperCase(Locale.ROOT))
                .filter(id -> !id.isEmpty())
                .collect(Collectors.toUnmodifiableSet());
        // 존재하지 않는 아이디도 같은 시간만큼 비교해, 응답 시간으로 계정 존재 여부를 추측하지 못하게 한다.
        this.dummyPasswordHash = passwordEncoder.encode("Soft2PreQcGate2-Dummy-Password");
    }

    @Override
    public LoginResponse loginLocal(LoginRequest request) {

        if (!localLogin.enabled()) {
            throw new ApiException("E314", HttpStatus.FORBIDDEN,
                    "아이디·비밀번호 로그인이 비활성화되어 있습니다. 회사 계정(SSO)으로 로그인하세요.");
        }

        String loginId = request.loginId().trim().toUpperCase(Locale.ROOT);
        authMapper.unlockExpiredUser(loginId);

        UserAccount user = authMapper.selectUserByLoginId(loginId);
        String passwordHash = user == null || user.passwordHash() == null ? dummyPasswordHash : user.passwordHash();
        boolean passwordMatches = passwordEncoder.matches(request.password(), passwordHash);

        if (user == null
                || !"Y".equals(user.useYn())
                || !"LOCAL".equals(user.authType())
                || !isAllowedLocalLoginId(loginId)) {
            throw loginFailed();
        }

        if (!passwordMatches) {
            if ("ACTIVE".equals(user.userStatus())) {
                authMapper.recordLoginFailure(user.userId(), localLogin.failureThreshold(), localLogin.lockMinutes());
            }
            throw loginFailed();
        }

        if ("LOCKED".equals(user.userStatus())
                && user.lockedUntil() != null
                && LocalDateTime.now().isBefore(user.lockedUntil())) {
            throw new ApiException("E306", HttpStatus.UNAUTHORIZED, "계정이 일시 잠겼습니다.");
        }

        if (!"ACTIVE".equals(user.userStatus())) {
            throw loginFailed();
        }

        log.info("Local login succeeded. loginId={}", loginId);
        return completeLogin(user);
    }

    @Override
    public LoginResponse completeLogin(UserAccount user) {

        List<String> roleCodes = authMapper.selectRoleCodes(user.userId());
        List<MenuPermission> menus = permissionService.calculate(
                authMapper.selectAllMenus(),
                authMapper.selectRoleMenuAuth(user.userId()));

        authMapper.recordLoginSuccess(user.userId());

        AuthSessionContext context = new AuthSessionContext(
                user.userId(),
                user.loginId(),
                user.userName(),
                user.deptId(),
                user.authType(),
                roleCodes,
                menus,
                null,
                null);

        AuthSessionService.IssuedSession issued = authSessionService.issue(context);

        return new LoginResponse(
                issued.accessToken(),
                user.userId(),
                user.loginId(),
                user.userName(),
                user.authType(),
                roleCodes,
                issued.context().expiresAt());
    }

    @Override
    public void logout(String accessToken) {
        authSessionService.logout(accessToken);
    }

    private boolean isAllowedLocalLoginId(String loginId) {
        return allowedLocalLoginIds.isEmpty() || allowedLocalLoginIds.contains(loginId);
    }

    private ApiException loginFailed() {
        return new ApiException("E301", HttpStatus.UNAUTHORIZED, "아이디 또는 비밀번호가 올바르지 않습니다.");
    }

}
```

```java
/**
```

```java
 *
 * 현재 가정한 방식 (확정 필요):
 *  1. 로그인 화면:  {login-url}?returnUrl={callback}&state={state}&systemCode={system-code}
 *  2. 돌아올 때:    callback 으로 token, state 파라미터를 GET 또는 POST 로 전달
 *  3. 사용자 확인: {verify-url} 로 token 을 POST(폼) → JSON 응답에서 사번(empNo) 등을 꺼냄
 *  4. 로그아웃:     {logout-url}?returnUrl={frontend}
 *
 * Ocean Dev 가 다른 방식(예: SAML, OpenID Connect, 암호화된 쿠키, 전용 에이전트 라이브러리)이면
 * 이 클래스의 verify() 내부만 그 방식으로 바꾼다.

@Component
public class OceanDevSsoProvider implements SsoProvider {

    private static final Logger log = LoggerFactory.getLogger(OceanDevSsoProvider.class);

    private final SsoProperties.OceanDev config;
    private final RestClient restClient;

    public OceanDevSsoProvider(SsoProperties ssoProperties) {
        this.config = ssoProperties.oceanDev();

        SimpleClientHttpRequestFactory requestFactory = new SimpleClientHttpRequestFactory();
        requestFactory.setConnectTimeout(Duration.ofSeconds(config.timeoutSeconds()));
        requestFactory.setReadTimeout(Duration.ofSeconds(config.timeoutSeconds()));
        this.restClient = RestClient.builder().requestFactory(requestFactory).build();
    }

    @Override
    public String id() {
        return "ocean-dev";
    }

    @Override
    public URI loginRedirectUri(String state, String callbackUrl) {
        String loginUrl = required(config.loginUrl(), "ocean-dev.login-url");
        SsoProperties.ParamNames names = config.paramNames();

        UriComponentsBuilder builder = UriComponentsBuilder.fromUriString(loginUrl)
                .queryParam(names.returnUrl(), callbackUrl)      // 확정 필요: 파라미터 이름
                .queryParam(names.state(), state);               // 확정 필요: state 를 되돌려 주는지
        if (hasText(config.systemCode())) {
            builder.queryParam(names.systemCode(), config.systemCode());
        }
        return builder.encode().build().toUri();
    }

    @Override
    public SsoIdentity verify(Map<String, String> callbackParams) {
        String verifyUrl = required(config.verifyUrl(), "ocean-dev.verify-url");
        SsoProperties.ParamNames names = config.paramNames();
        SsoProperties.AttributeNames attributeNames = config.attributeNames();

        String token = callbackParams.get(names.token());                    // 확정 필요
        if (!hasText(token)) {
            throw new ApiException("E502", HttpStatus.BAD_GATEWAY, "Ocean Dev 인증값이 전달되지 않았습니다.");
        }

        MultiValueMap<String, String> form = new LinkedMultiValueMap<>();
        form.add(names.token(), token);
        if (hasText(config.systemCode())) {
            form.add(names.systemCode(), config.systemCode());
        }
        if (hasText(config.clientSecret())) {
            form.add("clientSecret", config.clientSecret());                 // 확정 필요
        }

        Map<String, Object> response;
        try {
            response = restClient.post()
                    .uri(verifyUrl)
                    .contentType(MediaType.APPLICATION_FORM_URLENCODED)
                    .body(form)
                    .retrieve()
                    .body(new ParameterizedTypeReference<Map<String, Object>>() {});
        } catch (RestClientException exception) {
            log.warn("Ocean Dev verify call failed.", exception);
            throw new ApiException("E502", HttpStatus.BAD_GATEWAY, "Ocean Dev 사용자 확인에 실패했습니다.");
        }

        if (response == null) {
            throw new ApiException("E502", HttpStatus.BAD_GATEWAY, "Ocean Dev 응답이 비어 있습니다.");
        }

        // 확정 필요: 성공 여부 판단 항목 (예: resultCode == "0000")
        Object externalId = response.get(attributeNames.externalId());
        if (externalId == null || externalId.toString().isBlank()) {
            throw new ApiException("E502", HttpStatus.BAD_GATEWAY, "Ocean Dev 응답에 사번이 없습니다.");
        }

        return new SsoIdentity(
                externalId.toString().trim(),
                stringOrNull(response.get(attributeNames.name())),
                stringOrNull(response.get(attributeNames.email())),
                response);
    }

    @Override
    public Optional<URI> logoutRedirectUri(String returnUrl) {
        if (!hasText(config.logoutUrl())) {
            return Optional.empty();
        }
        return Optional.of(UriComponentsBuilder.fromUriString(config.logoutUrl())
                .queryParam(config.paramNames().returnUrl(), returnUrl)
                .encode()
                .build()
                .toUri());
    }

    private String required(String value, String propertyName) {
        if (!hasText(value)) {
            throw new ApiException("E315", HttpStatus.SERVICE_UNAVAILABLE,
                    "Ocean Dev 연동 설정이 없습니다: soft2preqcgate2.sso." + propertyName);
        }
        return value;
    }

    private static boolean hasText(String value) {
        return value != null && !value.isBlank();
    }

    private static String stringOrNull(Object value) {
        return value == null ? null : value.toString();
    }
```

```java
import org.springframework.stereotype.Service;
import org.springframework.web.util.UriComponentsBuilder;

import javax.crypto.Mac;
import javax.crypto.spec.SecretKeySpec;
import java.net.URI;
import java.nio.charset.StandardCharsets;

import java.security.MessageDigest;
import java.security.SecureRandom;
import java.time.Instant;
import java.util.Base64;

@Service
public class SsoServiceImpl implements SsoService {

    private static final Logger log = LoggerFactory.getLogger(SsoServiceImpl.class);

    private final SsoProperties properties;
    private final SsoProvider provider;          // 비활성화 상태이면 null
    private final AuthMapper authMapper;
    private final AuthSessionMapper authSessionMapper;
    private final AuthService authService;
    private final SecureRandom secureRandom = new SecureRandom();

    public SsoServiceImpl(SsoProperties properties,
                          List<SsoProvider> providers,
                          AuthMapper authMapper,
                          AuthSessionMapper authSessionMapper,
                          AuthService authService) {
        this.properties = properties;
        this.authMapper = authMapper;
        this.authSessionMapper = authSessionMapper;
        this.authService = authService;

        if (!properties.enabled()) {
            this.provider = null;
            return;
        }

        // 시작할 때 설정 누락을 바로 알린다.
        requireText(properties.callbackUrl(), "callback-url");
        requireText(properties.frontendRedirectUrl(), "frontend-redirect-url");
        if (properties.stateSecret() == null || properties.stateSecret().length() < 32) {
            throw new IllegalStateException("soft2preqcgate2.sso.state-secret must be at least 32 characters");
        }
        this.provider = providers.stream()
                .filter(candidate -> candidate.id().equals(properties.provider()))
                .findFirst()
                .orElseThrow(() -> new IllegalStateException(
                        "SSO provider not found (or not allowed in this profile): " + properties.provider()));
        log.info("SSO enabled. provider={}", provider.id());
    }

    @Override
    public SsoLoginUrlResponse createLoginUrl() {
        SsoProvider active = activeProvider();
        URI loginUri = active.loginRedirectUri(createState(), properties.callbackUrl());
        return new SsoLoginUrlResponse(active.id(), loginUri.toString());
    }

    @Override
    public URI handleCallback(Map<String, String> callbackParams) {
        try {
            SsoProvider active = activeProvider();
            verifyState(callbackParams.get("state"));

            SsoIdentity identity = active.verify(callbackParams);
            UserAccount user = authMapper.selectUserBySsoExternalId(identity.externalId());
            requireUsableSsoUser(user, identity.externalId());

            String ssoCode = randomToken();
            authSessionMapper.insertSsoHandoff(hash(ssoCode), user.userId(), properties.handoffTtlSeconds());

            log.info("SSO callback succeeded. loginId={}", user.loginId());
            return frontendUri("ssoCode", ssoCode);

        } catch (ApiException exception) {
            log.warn("SSO callback rejected. code={}, message={}", exception.code(), exception.getMessage());
            return frontendUri("ssoError", exception.code());
        }
    }

    @Override
    public LoginResponse exchange(String ssoCode) {
        activeProvider();

        String codeHash = hash(ssoCode);
        if (authSessionMapper.markSsoHandoffUsed(codeHash) != 1) {
            throw new ApiException("E313", HttpStatus.UNAUTHORIZED, "SSO 로그인 코드가 만료되었거나 이미 사용되었습니다.");
        }

        Long userId = authSessionMapper.selectSsoHandoffUserId(codeHash);
        UserAccount user = userId == null ? null : authMapper.selectUserById(userId);
        requireUsableSsoUser(user, null);

        return authService.completeLogin(user);
    }

    @Override
    public Optional<String> logoutUrl() {
        if (provider == null) {
            return Optional.empty();
        }
        return provider.logoutRedirectUri(properties.frontendRedirectUrl()).map(URI::toString);
    }

    // ===== 내부 처리 =====

    private SsoProvider activeProvider() {
        if (provider == null) {
            throw new ApiException("E315", HttpStatus.SERVICE_UNAVAILABLE, "SSO 로그인이 비활성화되어 있습니다.");
        }
        return provider;
    }

    private void requireUsableSsoUser(UserAccount user, String externalId) {
        if (user == null
                || !"SSO".equals(user.authType())
                || !"Y".equals(user.useYn())
                || !"ACTIVE".equals(user.userStatus())) {
            log.warn("SSO user is not registered or not active. externalId={}", externalId);
            throw new ApiException("E311", HttpStatus.FORBIDDEN,
                    "시스템 사용 권한이 없습니다. 관리자에게 등록을 요청하세요.");
        }
    }

    private URI frontendUri(String name, String value) {
        return UriComponentsBuilder.fromUriString(properties.frontendRedirectUrl())
                .queryParam(name, value)
                .encode()
                .build()
                .toUri();
    }

    /**
     * 위조 방지 값(state) = 난수.만료시각.서명
     * 서버에 저장하지 않고 서명(HMAC-SHA256)으로 검증한다. (Redis·세션 불필요)
     */
    private String createState() {
        long expiresAt = Instant.now().getEpochSecond() + properties.stateTtlSeconds();
        String payload = randomToken() + "." + expiresAt;
        return payload + "." + sign(payload);
    }

    private void verifyState(String state) {
        if (state == null || state.length() > 300) {
            throw invalidState();
        }
        String[] parts = state.split("\\.");
        if (parts.length != 3) {
            throw invalidState();
        }
        String payload = parts[0] + "." + parts[1];
        byte[] expected = sign(payload).getBytes(StandardCharsets.US_ASCII);
        byte[] actual = parts[2].getBytes(StandardCharsets.US_ASCII);
        if (!MessageDigest.isEqual(expected, actual)) {
            throw invalidState();
        }
        long expiresAt;
        try {
            expiresAt = Long.parseLong(parts[1]);
        } catch (NumberFormatException exception) {
            throw invalidState();
        }
        if (Instant.now().getEpochSecond() > expiresAt) {
            throw invalidState();
        }
    }

    private ApiException invalidState() {
        return new ApiException("E312", HttpStatus.BAD_REQUEST, "SSO 요청이 만료되었거나 올바르지 않습니다. 다시 로그인하세요.");
    }

    private String sign(String payload) {
        try {
            Mac mac = Mac.getInstance("HmacSHA256");
            mac.init(new SecretKeySpec(properties.stateSecret().getBytes(StandardCharsets.UTF_8), "HmacSHA256"));
            byte[] signature = mac.doFinal(payload.getBytes(StandardCharsets.UTF_8));
            return Base64.getUrlEncoder().withoutPadding().encodeToString(signature);
        } catch (GeneralSecurityException exception) {
            throw new IllegalStateException("HmacSHA256 is not available.", exception);
        }
    }

    private String randomToken() {
        byte[] bytes = new byte[32];
        secureRandom.nextBytes(bytes);
        return Base64.getUrlEncoder().withoutPadding().encodeToString(bytes);
    }

    private String hash(String value) {
        try {
            MessageDigest digest = MessageDigest.getInstance("SHA-256");
            return Base64.getUrlEncoder().withoutPadding()
                    .encodeToString(digest.digest(value.getBytes(StandardCharsets.UTF_8)));
        } catch (GeneralSecurityException exception) {
            throw new IllegalStateException("SHA-256 is not available.", exception);
        }
    }

    private static void requireText(String value, String name) {
        if (value == null || value.isBlank()) {
            throw new IllegalStateException("soft2preqcgate2.sso." + name + " is required when SSO is enabled");
        }
    }

}
```

## 16. 비상용 관리자 계정 생성 (`auth/bootstrap`)

### `EmergencyAdminInitializer.java`

```java
package com.soft2preqcgate2.auth.bootstrap;

import com.soft2preqcgate2.auth.mapper.AuthMapper;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.boot.ApplicationArguments;
import org.springframework.boot.ApplicationRunner;
import org.springframework.security.crypto.password.PasswordEncoder;
import org.springframework.stereotype.Component;
import org.springframework.transaction.annotation.Transactional;

import java.util.Locale;

/**
 * soft2preqcgate2.bootstrap.enabled=true 로 한 번 실행하면 비상용 LOCAL 관리자 계정을 만든다.
 * 이미 있으면 아무것도 하지 않는다. 비밀번호는 환경 변수 S2P_ADMIN_PASSWORD 로만 받는다.
 */
@Component
public class EmergencyAdminInitializer implements ApplicationRunner {

    private static final Logger log = LoggerFactory.getLogger(EmergencyAdminInitializer.class);

    private final AuthMapper authMapper;
    private final PasswordEncoder passwordEncoder;
    private final boolean enabled;
    private final String loginId;
    private final String adminName;
    private final String adminPassword;

    public EmergencyAdminInitializer(
            AuthMapper authMapper,
            PasswordEncoder passwordEncoder,
            @Value("${soft2preqcgate2.bootstrap.enabled:false}") boolean enabled,
            @Value("${soft2preqcgate2.bootstrap.admin-login-id:ADMIN}") String loginId,
            @Value("${soft2preqcgate2.bootstrap.admin-name:비상관리자}") String adminName,
            @Value("${soft2preqcgate2.bootstrap.admin-password:}") String adminPassword
    ) {
        this.authMapper = authMapper;
        this.passwordEncoder = passwordEncoder;
        this.enabled = enabled;
        this.loginId = loginId.trim().toUpperCase(Locale.ROOT);
        this.adminName = adminName;
        this.adminPassword = adminPassword;
    }

    @Override
    @Transactional
    public void run(ApplicationArguments args) {
        if (!enabled) {
            return;
        }
        if (authMapper.selectUserByLoginId(loginId) != null) {
            log.info("Emergency admin already exists. loginId={}", loginId);
            return;
        }
        if (adminPassword == null || adminPassword.length() < 12) {
            throw new IllegalStateException("S2P_ADMIN_PASSWORD must be at least 12 characters");
        }
        authMapper.insertLocalUser(loginId, adminName, passwordEncoder.encode(adminPassword));
        authMapper.insertUserRoleByCode(loginId, "SYSTEM_ADMIN");
        log.info("Emergency admin created. loginId={}", loginId);
    }

}
```

## 17. Nexacro 쪽 연결 약속 (요약)

Nexacro 화면 코드는 별도 보고서(`docs/reports/nexacro/`)로 작성하는 것이 지침에 맞습니다. 여기서는 API 약속만 정리합니다.

| 화면 동작 | 호출 | 결과 처리 |
|---|---|---|
| 앱 시작 | 주소에 `ssoCode`가 있으면 → `POST /api/v1/auth/sso/exchange` | `accessToken` 저장 → 메인 화면 |
| 앱 시작 | 주소에 `ssoError`가 있으면 | 오류 안내 (E311: 사용 권한 없음, E312: 다시 로그인 등) |
| 앱 시작 | 둘 다 없고 저장된 토큰도 없으면 → `GET /api/v1/auth/sso/login-url` | 브라우저 주소를 `loginUrl`로 이동 |
| 비상 로그인 (관리자만) | `POST /api/v1/auth/login` | `accessToken` 저장 → 메인 화면 |
| 메인 화면 | `GET /api/v1/navigation/menus` (헤더 `X-Auth-Token`) | 메뉴 트리 구성 |
| 로그아웃 | `POST /api/v1/auth/logout` | 응답의 `ssoLogoutUrl`이 있으면 그 주소로 이동 |

> Nexacro 웹 브라우저 실행이므로 주소 이동(`window.location.href`)과 주소 파라미터 읽기(`window.location.search`)를 그대로 쓸 수 있습니다. 교환 코드를 읽은 뒤에는 주소창에서 `ssoCode`를 지워 새로고침 때 다시 쓰지 않도록 합니다.

## 18. 실행 순서 (개발 환경)

1. 환경 변수: `S2P_DB_URL`, `S2P_DB_USERNAME`, `S2P_DB_PASSWORD`
2. 첫 실행 한 번만 `S2P_BOOTSTRAP_ENABLED=true`, `S2P_ADMIN_PASSWORD=(12자 이상)` → 비상용 `ADMIN` 생성. 이후 `false`로 되돌림.
3. 비상 로그인 확인:
   ```http
   POST http://localhost:8082/api/v1/auth/login
   Content-Type: application/json

   {"loginId": "ADMIN", "password": "(비밀번호)"}
   ```
4. 가짜 SSO 확인 (브라우저):
   1. `GET http://localhost:8082/api/v1/auth/sso/login-url` → 응답의 `loginUrl`을 브라우저로 열기
   2. 가짜 로그인 화면에서 사번 `E12345` → [로그인]
   3. `http://localhost:9092/index.html?ssoCode=...`로 이동되는지 확인
   4. `POST /api/v1/auth/sso/exchange {"ssoCode": "..."}` → `accessToken`, `loginId: HONG`
   5. `GET /api/v1/navigation/menus` + `X-Auth-Token` → `Pre QC Gate` / `QC Gate 목록`(R) 메뉴
5. 사번 `E99999`(미등록)로 시도 → `?ssoError=E311`로 이동되는지 확인
